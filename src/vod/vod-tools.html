다시보기 선택

다시보기 주소를 선택해 주세요. 수집은 시작 버튼을 눌러야 실행됩니다.

채팅 수집

수집 범위

다시보기 시작 기준 · HH:MM:SS.mmm 또는 초 단위

수집 대기 중

이 탭을 열어 둔 동안 수집합니다. 중단된 작업은 저장된 지점에서 직접 이어갈 수 있습니다. API 응답만으로 전체 채팅의 완전성을 보장할 수 없습니다.

저장된 수집 작업

    CSV 다운로드

    각 파일 링크를 눌러 저장하세요. 다운로드 준비는 디스크 저장 완료를 뜻하지 않습니다.

      타임스탬프 메모

      선택한 다시보기의 열린 CHZZK 탭에서 찾습니다. 시각을 직접 입력해도 됩니다.

      새 메모

      다시보기 시작 기준 · HH:MM:SS.mmm 또는 초 단위

      메모는 이 브라우저의 확장 저장소에 보관됩니다.
