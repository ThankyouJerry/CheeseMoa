## 상세 설명

**보고 싶은 CHZZK 방송을 한곳에 모아보세요.**

치즈모아는 여러 CHZZK 라이브와 다시보기를 하나의 Chrome 탭에 배치하는 로컬 멀티뷰 확장
프로그램입니다. 별도 회원가입이나 외부 멀티뷰 서버 없이 브라우저에서 바로 실행됩니다.

**주요 기능**

- CHZZK 라이브와 다시보기 URL 여러 개 동시 입력
- 방송 수에 맞춘 1~3열 자동 화면 배치
- 자동, 1열, 2열, 3열 수동 레이아웃
- 개별 방송 새로고침, 제거와 전체화면
- 동일 링크 중복 방지
- Chrome에 로그인된 기존 CHZZK 세션 사용
- 방송 목록을 현재 Chrome 프로필에만 저장
- 방송 추가·삭제와 배치 변경 시 다른 방송의 플레이어 유지
- 기존 멀티뷰 탭 재사용, 방송 표시 이름 지정과 열 수 저장
- 원본 방송 바로 열기, 잘못된 링크 안내와 저장 오류 처리

**사용 방법**

1. 도구 모음에서 치즈모아 아이콘을 누릅니다.
2. CHZZK 라이브 또는 다시보기 URL을 한 줄에 하나씩 입력합니다.
3. `방송 모아보기`를 눌러 멀티뷰를 엽니다.
4. 상단 버튼으로 원하는 화면 배치를 선택합니다.

**개인정보 보호**

치즈모아에는 분석 서버, 광고 SDK 또는 사용자 추적 코드가 없습니다. 입력한 CHZZK URL은
지정한 표시 이름, 마지막 스트리머명 및 화면 배치와 함께 사용자 PC의 현재 Chrome 프로필에만 저장·적용됩니다. 다른 기기나 사용자에게 동기화하거나 개발자 서버로 전송하지 않습니다. 방송 재생 및 정보 조회 시 Chrome이 CHZZK 페이지와 API에 방송 URL 또는 ID로 접속합니다. 로그인 쿠키를 읽거나 복사하지
않습니다.

치즈모아는 CHZZK 또는 NAVER의 공식 서비스가 아닌 독립 오픈소스 프로젝트입니다.

## 권한 정당화

### Storage

사용자가 직접 추가한 CHZZK 방송 URL 목록, 표시 이름과 마지막 스트리머명을 사용자 PC의 현재 Chrome 프로필에 저장하고 다음 실행에서 복원합니다. 개발자 서버로 업로드하거나 다른 사용자에게 공유하지 않습니다.

### Host permission: `https://chzzk.naver.com/*`

사용자가 입력한 CHZZK 라이브와 다시보기 페이지를 확장 프로그램 내 멀티뷰 프레임으로
불러오고 콘텐츠 스크립트로 영상 요소의 위치·크기를 읽어 칸 안 확대에 사용합니다. 측정값은 저장하거나 개발자 서버로 보내지 않습니다. 채팅과 로그인 쿠키를 읽어 수집하지 않습니다.

## 검토자 테스트 절차

1. 확장 프로그램을 설치합니다.
2. 도구 모음의 치즈모아 아이콘을 엽니다.
3. 현재 공개 재생 가능한 CHZZK 라이브 또는 다시보기 링크 두 개를 줄 단위로 입력합니다.
4. `방송 모아보기`를 누릅니다.
5. 두 방송이 자동 2열로 표시되는지 확인합니다. 자동 재생이 제한되면 각 플레이어의 재생 버튼을 누릅니다.
6. 1열·2열·3열 전환, 새로고침, 전체화면과 제거를 확인합니다.
7. 멀티뷰를 다시 열어 URL 목록이 로컬에서 복원되는지 확인합니다.
8. 배치 변경과 한 방송 제거 시 다른 방송이 처음부터 다시 로딩되지 않는지 확인합니다.
9. 방송 목록의 이름 버튼으로 표시 이름을 바꾸고, 팝업에서 멀티뷰 열기를 눌러 기존 탭으로 이동하는지 확인합니다.

## v0.1.3 업데이트 안내

방송 목록이나 화면 배치를 바꿔도 다른 방송은 그대로 유지됩니다. 여러 창에서의 목록 저장 충돌을 방지하고, 기존 멀티뷰 탭 재사용·방송 이름 지정·배치 저장·원본 방송 열기를 추가했습니다. Chrome 116 이상을 지원합니다.

### 다음 업데이트: 방송 정보 조회 권한

`https://api.chzzk.naver.com/*`는 추가한 방송의 스트리머명과 방송제목을 표시하기 위해 사용합니다. 방송 ID로 쿠키 없이 요청하며 개발자 서버로 전송하지 않습니다. 스토어 제출 시 이 호스트 권한 추가를 반영해야 합니다.
