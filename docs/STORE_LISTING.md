# Chrome 웹 스토어 제출 문구 — 0.1.16

치즈모아 - CheeseMoa 0.1.16 · Chrome 웹 스토어 등록 문구 (한국어)
기준: 0.1.16 / power-20261026.2 검증빌드 · 문서 갱신일 2026-10-27
상태: 제출 전 문구 초안. 클라우드 회귀검증 진행 중이며 게시·설치본 갱신을 수행하지 않았습니다. 과거 0.1.15 문구 검토 기록은 이 초안의 검토 완료를 뜻하지 않습니다.

==================================================
[짧은 설명]
==================================================
치지직 라이브·다시보기를 한 화면 최대 4칸에 모아 보는 비공식 로컬 멀티뷰. 칸별 재생 시작·음량 조절과 공식 화질 메뉴 열기 보조.

==================================================
[상세 설명]
==================================================
치즈모아는 여러 치지직(CHZZK) 방송을 브라우저 한곳에 모아 보는 로컬 멀티뷰 확장 프로그램입니다. 별도의 멀티뷰 서버 없이 사용 중인 Chrome 안에서 동작합니다.

※ 치즈모아는 NAVER 또는 CHZZK가 만들거나 승인·후원한 공식 서비스가 아닌 독립적인 비공식 프로젝트입니다. CHZZK 명칭은 호환 대상을 설명하기 위해서만 사용합니다.

■ 주요 기능
• 방송 모으기: 치지직 라이브·다시보기 주소를 붙여 넣거나, 채널 이름 검색 또는 로그인한 계정의 팔로잉 라이브 목록에서 골라 추가합니다.
• 1~4칸 보기: 멀티뷰 화면(chzzk.naver.com/lives#cheesemoa-multiview)에서 1개부터 4개까지 보기를 고르고, 각 칸에 표시할 방송을 선택합니다.
• 칸별 직접 시작: 방송은 각 칸의 ‘방송 시작’을 눌렀을 때만 불러옵니다. 칸마다 정지, 음소거, 음량 조절, 전체화면, ‘영상 맞춤/전체 페이지’ 전환을 할 수 있습니다.
• 공식 화질 메뉴 열기: 각 칸의 ‘화질 메뉴’ 버튼은 해당 방송의 공식 플레이어에서 설정 → 해상도 메뉴 열기를 돕습니다. 공식 UI 상태에 따라 직접 열어야 할 수 있습니다. 화질은 자동으로 바뀌지 않으며, 원하는 해상도는 사용자가 공식 메뉴에서 직접 선택합니다.
• 재생 진단(선택): 진단 정보는 기본적으로 숨겨져 있습니다. 칸의 ‘재생 진단’을 누르면 요청 시점의 재생 상태가 영상 영역 아래에 표시되며, ‘닫기’로 다시 숨길 수 있습니다.
• VOD 채팅·메모: 별도 도구에서 공개 다시보기 채팅 수집을 직접 시작하고, 저장된 결과를 CSV 파일로 내보냅니다. 일시정지·수동 재개·작업별 삭제를 지원하며 부분 결과와 완전성 미검증 상태를 표시합니다. 다시보기 시각별 메모를 추가·수정·삭제하고, 직접 선택한 열린 플레이어의 시각을 가져오거나 메모 시각으로 이동할 수 있습니다. 라이브 채팅 수집과 클라우드 동기화는 지원하지 않습니다.
• 프리셋: 방송·배치·음량 조합을 최대 10개까지 이 브라우저에 저장해 다시 불러올 수 있습니다.
• 통나무파워 보상 자동 확인(자동수령): 선택한 주 라이브 채널 1개에 대해, 서버가 ‘수령 가능’으로 표시한 보상이 있는지 일정 간격으로 확인하고 해당 보상에 대해서만 수령 요청을 보냅니다. 새로 설치했거나 설정을 저장한 적이 없으면 기본값은 OFF이며 사용자가 ON을 선택해야 시작합니다. 방송 화면의 자동수령 패널에서 언제든 OFF로 끌 수 있습니다. 저장된 ON/OFF 선호값과 현재 실행 중의 OFF 설정은 그대로 유지됩니다. 보상의 발생·적립·수령을 보장하지 않으며, 동시에 여러 방송을 시청해도 시청 시간은 한 방송만 집계될 수 있습니다. 팔로우·후원·구독을 대신 실행하지 않습니다.

■ 알아 두세요
• 방송 재생은 치지직 공식 플레이어와 네트워크 상태에 따라 달라지며, 끊김 없는 재생을 보장하지 않습니다.
• 로그인은 브라우저와 치지직이 직접 관리합니다. 치즈모아는 쿠키 값을 읽거나 저장하지 않습니다.

[단일 목적 (Single purpose)]
==================================================
치즈모아의 단일 목적은 사용자가 고른 여러 치지직(CHZZK) 라이브·다시보기 방송을 브라우저의 한 화면에 모아 보는 멀티뷰 시청 환경을 제공하는 것입니다. 채널 검색·추가, 칸별 재생·음량 제어, 공식 화질 메뉴 열기, 재생 진단, 다시보기의 공개 채팅 열람을 위한 수집·CSV 내보내기와 시각별 메모, 그리고 시청 중인 주 채널의 통나무파워 보상 확인·수령은 모두 이 멀티뷰 시청을 보조하는 기능입니다.

==================================================
[권한 사유 (Permission justification)]
==================================================
manifest.json의 permissions: storage
manifest.json의 host_permissions: https://chzzk.naver.com/*, https://api.chzzk.naver.com/*, https://comm-api.game.naver.com/*
(그 외 content_scripts 대상은 모두 https://chzzk.naver.com 하위 경로입니다.)

1) storage
사용자가 추가한 방송 목록(주소, 표시 이름, 마지막으로 확인한 스트리머명, 관리 화면에서 저장한 채널별 음량·음소거), 관리 화면의 배치 설정, 프리셋(최대 10개), 자동수령 ON/OFF 설정, 자동수령 패널 위치·숨김 설정, 통나무파워 보유량 조회 기록·수령 기록(최근 1,000건)·중복 수령 방지 기록(최대 2,000건)을 현재 Chrome 프로필에 저장합니다(chrome.storage.local 및 관리 화면의 일부 배치 설정은 확장 페이지 localStorage). 동일 출처 멀티뷰의 1~4칸 선택과 해당 화면에서 조절한 음량은 실행 중 상태이며 저장·복원을 보장하지 않습니다. 자동수령 실행 창 상태는 브라우저 세션 범위의 chrome.storage.session에 둡니다. chrome.storage.sync는 사용하지 않습니다. 공개 VOD 채팅 작업·행은 확장 출처 IndexedDB cheesemoa.vod-chat, 시각별 메모는 별도 IndexedDB cheesemoa.vod-notes.v1에 저장합니다. 이 기능을 위해 새 권한을 추가하지 않습니다.

2) https://chzzk.naver.com/*
멀티뷰 화면을 chzzk.naver.com/lives#cheesemoa-multiview 페이지 안에 구성하고(콘텐츠 스크립트 site-host.js), 사용자가 시작한 방송을 각 칸에 공식 치지직 플레이어로 불러옵니다. 각 방송 페이지(/live/*, /video/*)의 콘텐츠 스크립트(player-frame.js)는 영상 영역 위치 측정과 음소거·음량 적용에만 사용하고, power-page.js는 자동수령 패널과 계정 확인·보상 요청 처리, 1시간 보상의 공식 받기 버튼 조작과 후속 조회 확인을 수행합니다. site-host.js는 멀티뷰 구성·제어와 재생 상태 확인·진단 및 공식 메뉴 열기를 보조합니다. ‘화질 메뉴’ 버튼은 이 권한으로 공식 플레이어의 설정 → 해상도 메뉴 열기를 돕습니다. 공식 UI 상태에 따라 직접 열어야 할 수 있으며 최종 화질 선택은 사용자에게 맡깁니다.

vod-frame.js는 사용자가 요청할 때 VOD 플레이어를 찾고 선택한 플레이어의 상대 시각 확인·이동을 처리합니다. 메모 본문을 CHZZK 페이지로 보내지 않습니다.

3) https://api.chzzk.naver.com/*
• 공개 방송 정보 조회: 추가한 방송의 스트리머명·방송 제목(쿠키 없이 요청), 채널 이름 검색(쿠키 없이 요청).
• 공개 VOD 채팅: 사용자가 수집 시작 또는 이어 수집을 누르면 /service/v1/videos/{videoId}/chats에 VOD ID와 상대 시각을 보내고 credentials: omit으로 쿠키 없이 요청합니다. 도구 탭을 닫으면 중단되며 자동 재개하지 않습니다.
• 팔로잉 라이브 목록: 사용자가 요청할 때 브라우저의 기존 로그인 세션으로 조회합니다.
• 통나무파워: 자동수령이 켜져 있을 때 선택한 주 채널의 보유량·수령 가능 보상 조회(GET)를 기존 로그인 세션으로 보냅니다. 1시간 시청 보상은 공식 받기 버튼으로 처리하며 해당 보상의 claim PUT은 직접 보내지 않습니다. 버튼 클릭 후 같은 보상 ID가 목록에서 사라지고 보유량이 필요한 만큼 증가해야 공식 UI 수령으로 기록합니다. 결과가 불명확하면 미확인으로 남기고 자동 재클릭하지 않습니다. 다른 허용 보상 경로에는 수령 요청(PUT)이 사용될 수 있습니다.

4) https://comm-api.game.naver.com/*
로그인 상태 확인(/nng_main/v1/user/getUserStatus)에 사용합니다. 팝업의 ‘로그인 상태 확인’ 버튼을 누르거나 자동수령이 동작할 때 요청하며, 자동수령에서는 계정이 바뀌었는지 확인해 다른 계정 기록과 섞이지 않도록 하는 데 씁니다.

원격 코드: 확장 자체 코드는 패키지에 포함되며 외부에서 내려받아 실행하지 않습니다. 공식 CHZZK 페이지는 자체 스크립트와 CDN 등 별도 리소스를 사용할 수 있으며 해당 서비스 정책이 적용됩니다.

[데이터 사용 및 개인정보 설명]
==================================================
• 개발자 서버 없음: 확장 자체 코드가 직접 요청하는 호스트는 chzzk.naver.com, api.chzzk.naver.com, comm-api.game.naver.com 뿐입니다. 개발자 서버, 분석 도구, 광고 네트워크로 데이터를 보내지 않습니다.
• 이 브라우저에만 저장(chrome.storage.local / 확장 페이지 localStorage): 방송 목록과 표시 이름·스트리머명·관리 화면에서 저장한 음량, 관리 화면의 배치 설정, 프리셋, 자동수령 ON/OFF 설정, 자동수령 패널 위치·숨김, 통나무파워 기록(채널 ID, 보상 ID와 종류, 요청·확인 시각, 제공 보상량, 처리 상태, 조회한 보유량).
• VOD 채팅·메모(확장 출처 IndexedDB): 채팅에는 VOD URL·ID, 상대 시각, 공개 닉네임·메시지·제공된 메시지 ID와 수집 범위·상태·저장 지점·중복 처리용 해시·요청 횟수·작업 시각을 보관합니다. 원본 채팅 프로필과 작성자 userIdHash는 보관하지 않습니다. 메모에는 사용자가 입력한 본문·상대 시각·VOD 식별자와 로컬 ID·버전·생성 및 수정 시각을 보관합니다. 메모 본문은 외부로 전송하지 않습니다. 채팅 행 데이터는 작업당 32 MiB·250,000행, 체크포인트 등을 포함한 계산상 전체 저장량 96 MiB(실제 디스크 사용량과 다름), 메모는 전체 5,000개·2 MiB·개당 2,000자로 제한하며 더 이른 브라우저 저장 실패가 있을 수 있습니다.
• 가명 계정 키: 계정별 기록 구분을 위해, 로그인 확인 응답의 userIdHash에 서비스 구분 문자열을 붙여 SHA-256으로 계산한 값을 로컬 기록에 함께 저장합니다. 로그인 확인 응답의 원래 userIdHash, 닉네임 등 프로필 정보와 쿠키 값은 저장하지 않습니다. 공개 VOD 채팅 닉네임·본문은 위 항목과 같이 별도 보관합니다. 이 값은 익명 값이 아니라 같은 계정을 구분하기 위한 가명 식별값입니다.
• 검색어는 검색 시 CHZZK API로 전송하며 검색 이력은 저장하지 않습니다. 검색 결과·팔로잉 목록·재생 진단·영상 영역 측정값은 기능 처리를 위해 메모리에서 사용하며 개발자 서버로 보내지 않습니다. 선택해 추가한 방송은 목록에 저장합니다.
• 사용자 데이터를 판매하거나 광고·분석 목적으로 제공하지 않으며 개발자 서버로 전송하지 않습니다. 기능에 필요한 NAVER/CHZZK 요청은 위 통신 설명에 포함했습니다.
• 삭제: 목록에서 방송을 개별 삭제할 수 있고, 수령 성공 내역 삭제 기능이 있습니다(중복 방지 기록은 재수령 방지를 위해 유지). 모든 데이터는 확장 프로그램을 제거하거나 확장 저장 데이터를 삭제하면 지워집니다.
• VOD 삭제·내보내기: 작업 삭제는 해당 채팅과 체크포인트를 삭제하고 메모는 개별 삭제합니다. 이 삭제는 통나무파워 계정 키·영수증·시도·중복 방지 기록을 변경하지 않습니다. CSV는 작업 상태·출처와 함께 부분 결과를 내보낼 수 있으며 수식으로 해석될 수 있는 문자열을 작은따옴표로 처리합니다. 파일 링크를 직접 눌러 저장하며, 다운로드한 파일은 사용자가 따로 삭제해야 합니다.
• 로컬에서 처리·저장하는 데이터도 개인정보 처리방침에 공개합니다.
