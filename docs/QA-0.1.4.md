# 0.1.4 제출 전 점검

2026-09-26 로컬 점검. GitHub Actions 또는 실제 Chrome 전체 재생 검증 결과가 아닙니다.

## 수정한 누락

- 콘텐츠 스크립트 준비 전에 도착한 확대 요청: 준비 알림을 받으면 활성 확대 요청을 다시 전달합니다.
- 영상 요소가 사라진 뒤 남아 있던 확대 영역: 측정 실패 시 원래 채널 페이지로 되돌려 안내를 확인할 수 있게 합니다.
- API의 잘못된 필드 형식: 문자열만 받아 길이를 제한하고 저장된 이름을 보호합니다.
- 개인정보와 스토어 설명: 외부 API가 없다는 이전 표현을 수정하고 사용자 PC의 현재 Chrome 프로필에만 저장·적용함을 명시했습니다. CHZZK 접속과 개발자 서버 업로드를 구분했습니다.

## 결과

- 자동 테스트 20개 통과.
- manifest 및 필수 파일 14개 검증 통과.
- 0.1.4 배포 ZIP 빌드, 압축 무결성, SHA-256 검증 통과.
- 제출 이미지 3개: 1280×800 JPEG, 알파 없음. 실제 캡처 내용과 제목 배치를 시각 확인했습니다.
- 4칸 유지, iframe 유지, 준비 메시지, 잘못된 메시지 출처 거부, 영상 사라짐 복원, 로컬 이름 보존을 자동 검사했습니다.

## 한계와 미완료

- 실제 브라우저 도구 접근 제한으로 최종 ZIP 설치본의 실재생 재검증은 하지 않았습니다. 사용자 제공 화면에서 표시 사례를 확인한 것과 자동 테스트를 구분합니다.
- CHZZK 광고 차단 경고의 원인은 확정하지 않았으며 해결됐다고 주장하지 않습니다.
- 장시간 재생, 로그인 제한 방송, CHZZK 페이지 변경에 대한 호환성은 보장하지 않습니다.
- 공개 개인정보 정책 갱신, GitHub 커밋·푸시, Chrome Web Store 심사 제출은 이번 점검에서 수행하지 않았습니다.
