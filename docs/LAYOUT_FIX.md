# 다중 방송 화면 맞춤 수정

- 각 카드 상단의 `칸 안 영상 확대`는 해당 카드 안에서 영상 영역만 확대합니다. 다른 카드와 행/열 배치는 바꾸지 않습니다. `채널 화면 복원`으로 되돌립니다.
- `전체화면`은 선택 채널 카드만 브라우저 전체화면으로 표시하는 별도 기능입니다.
- 모든 채널 iframe을 그대로 유지하며 확대를 위해 재로드하지 않습니다. 치지직 프레임 안의 영상 위치를 측정하여 해당 영역만 표시합니다. 사이트 DOM과 재생 요청은 수정하지 않습니다.

- 카드의 고정 16:9 높이 대신 남은 창 높이를 행별로 나눕니다. 자동 배치에서 방송 4개는 2열 2행입니다.
- 카드 내부는 최소 1280×720 크기의 치지직 페이지 전체를 비율 유지 축소합니다. 영상만 줄고 메뉴와 채팅이 잘리는 현상을 줄입니다.
- 창 크기 및 카드 전체화면 변경 시 크기를 다시 계산하며 iframe을 교체하거나 주소를 다시 설정하지 않습니다.
- 여러 방송을 한 화면에 넣으면 글자와 버튼도 작아집니다. 개별 전체화면 또는 치지직에서 열기로 크게 볼 수 있습니다.

검증: 자동 테스트 15개 통과, manifest 및 정적 파일 검증 통과. 실제 Chrome 치지직 화면 및 재생 확인은 미완료입니다. 스토어 배포 전 시각 확인이 필요합니다.
