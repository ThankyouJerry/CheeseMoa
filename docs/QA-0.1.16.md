# 0.1.16 검증 범위와 진행 상태

실행 표식: `power-20261026.2`. 현재 소스는 미배포 검증빌드입니다. 이 문서는 배포·스토어 제출·실제 설치본 갱신을 의미하지 않습니다.

## 확인할 동작

- 새 설정은 기본 OFF. 저장된 ON/OFF 선호값 및 실행 중 OFF 보존.
- 기존 계정·채널·보상 ID, 영수증·시도·중복 방지 기록 보존.
- 1시간 보상은 공식 받기 버튼 사용. 직접 claim PUT 금지.
- 클릭 후 같은 보상 ID가 수령 가능 목록에서 사라지고 필요한 보유량 증가가 함께 확인된 경우만 수령 기록 생성. 직접 수령 HTTP 응답을 확인한 것으로 표시하지 않음.
- 클릭 후 문서·채널·실행 소유권을 잃거나 확인에 실패하면 미확인 처리하고 자동 재클릭하지 않음.

## VOD 채팅·메모 검증 항목

다음은 현재 구현에 대한 확인 항목이며, 이 목록 자체가 통과 결과는 아닙니다. 최종 실행 로그와 실서비스 확인 결과는 별도로 기록해야 합니다.

- 팝업에서 도구 열기와 VOD 선택만으로 네트워크 수집하지 않음. 유효한 VOD만 수락하고 라이브·잘못된 URL 거부. `채팅 수집 시작`·`이어 수집`만 공개 API에 `credentials: omit`으로 요청.
- 시작 포함·종료 제외 상대 시각 범위, 페이지 경계의 중복 처리, 동일 시각의 서로 다른 메시지 보존, 반복 경계·이전 시각 응답에서 부분 중단. 빈 응답 3회 또는 범위 끝으로 종료해도 전체 완전성 미검증 표시 유지.
- 재시도 가능한 오류의 제한된 재시도, 긴 Retry-After 대기, 요청 타임아웃, 사용자의 중단과 탭 종료 처리. 재개는 마지막 원자적 저장 지점에서 수동 실행하며 중복 창 수집 차단. 누적 한도는 재개로 초기화되지 않음.
- 작업당 32 MiB·250,000행·10,000페이지·12,000요청·누적 2시간, 체크포인트 등을 포함한 계산상 전체 채팅 저장량 96 MiB, 응답 4 MiB·행 64 KiB 및 브라우저 저장 실패에서 기존 체크포인트 보존·오류 표시.
- CSV의 UTF-8 BOM·따옴표·쉼표·줄바꿈·한글, 수식 시작 문자열과 선행 제어문자 처리, 출처·시각·상태·범위·완전성 열, 파일당 8 MiB·총 96 MiB 한도. 부분·실패·일시정지 작업 내보내기와 링크 준비/디스크 저장 구분.
- 메모 추가·수정·삭제·재로드, VOD별 분리와 상대 시각 정렬, 전체 5,000개·2 MiB·개당 2,000자 한도, 다중 창 수정 충돌·저장 실패 안내.
- 플레이어를 직접 선택한 뒤 시각 가져오기·이동. 같은 VOD의 여러 탭·프레임 구분, 다른 VOD·탭 이동·문서 교체·응답 지연·위조 메시지 거부, 준비 안 된 영상과 이동 불가 구간 안내. 메모 본문이 플레이어 메시지에 포함되지 않음.
- 채팅과 메모가 각각 확장 출처 IndexedDB에만 저장되고, 작업 삭제·메모 삭제가 통나무파워 계정 키·영수증·시도·중복 방지 기록에 영향을 주지 않음. 새 권한·클라우드 전송·라이브 채팅 수집 없음.
- UI 키보드 조작·상태 안내·모바일 폭, 내보내기 링크 교체 시 객체 URL 해제 및 탭 종료 시 요청·리스너 정리.

실제 CHZZK 서비스의 페이지 경계 규칙과 채팅 누락 여부, 접근 제한된 VOD 동작, 공식 플레이어의 시각 연동은 오프라인 fixture 테스트만으로 검증할 수 없습니다. 서비스에서 관측한 결과가 없으면 미검증으로 남깁니다.

## 진행 상태

2026-10-27 클라우드 검증: Node 24.19.0에서 전체 538/538 테스트, manifest 및 45개 자산 검사, 빌드, ZIP 소스 대조, 모의 자동수령 11/11이 통과했습니다. 별도 Chromium/Playwright localhost 검증 20/20도 통과했습니다. 실제 IndexedDB 다중 탭 저장·충돌·트랜잭션 롤백, 메모 CRUD·재로드, 채팅 중단·재개, CSV 다운로드, 모바일 화면과 합성 영상의 SPA·교체를 확인했습니다. 콘솔 오류와 외부 요청은 없었습니다.

검증 기준은 성공본 df98ca74727eab6b00ab8eabd28b00b0bb1310fe 위의 클라우드 작업 변경입니다. package·manifest·RELEASE_NOTES는 0.1.16으로 일치합니다. 기존 40개 실패는 비시간 보상의 PUT fixture, 저장 ON/기본 OFF 계약, 화면 안내와 릴리스 메타데이터를 맞춰 해결했습니다. 별도로 공식 UI 확인 잔액 덮어쓰기 및 여러 시간 보상 중 버튼 오귀속 가능성을 재현하고 수정했습니다.

실계정 수령·채팅 API·실제 CHZZK 영상, 설치된 확장 end-to-end, 물리 디스크 고갈/OS 저장 거절, CI Node 22 실행은 이번 로컬 검증에 포함하지 않았습니다. API 페이지 완전성은 UI/CSV에서도 미확인으로 표시합니다. 설치·게시·배포·추가 push는 수행하지 않았습니다.
